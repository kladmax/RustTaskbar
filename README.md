# Програма для відстеження простою і керування енергоспоживанням

## Опис програми

Ця програма призначена для автоматизації керування енергоспоживанням на комп'ютері та моніторингу активності користувача. Вона виконує наступні основні функції:

1. **Відстеження простою користувача** — програма контролює активність клавіатури та миші користувача, щоб визначити, чи пристрій не використовується певний період часу.
2. **Кнопка керування таймером простою** — надає можливість вручну запускати або зупиняти таймер, який контролює стан простою.
3. **Керування енергоспоживанням** — після досягнення заданого періоду простою програма активує функцію для переходу в режим гібернації, щоб зберегти енергію. Також підтримується активний стан системи, що запобігає переходу в режим сну.

## Функції програми

### Основні функції
- **Відстеження активності користувача:** програма постійно моніторить активність миші та клавіатури. При виявленні простою запускається таймер для підрахунку тривалості неактивного стану.
- **Керування таймером простою:** користувач може вручну активувати або зупинити таймер простою. При досягненні встановленого інтервалу таймер активує режим гібернації.
- **Гібернація:** програма автоматично переводить систему в режим гібернації при досягненні заданого інтервалу простою для збереження енергії.
- **Підтримка активного стану:** програма може запобігти переходу комп'ютера в сплячий режим, підтримуючи активний стан екрану та системи.

### Компоненти програми
- `main.rs` — точка входу в програму, забезпечує ініціалізацію та налаштування основних компонентів.
-  містить налаштування програми, де визначаються конфігураційні параметри.
-  відповідає за створення графічного інтерфейсу для взаємодії з користувачем.
-  обробляє функції керування енергоспоживанням, включаючи активацію гібернації та підтримку активного стану системи.
-  таймер, що відстежує період простою користувача і запускає гібернацію після досягнення встановленого часу.
-  містить логіку для кнопки управління таймером простою.
-  основна логіка програми, координує роботу всіх компонентів.

Наочна структура програми знаходиться в файлі .txt, який містить опис компонентів та їх взаємодії.

## Вимоги
- **Rust** — для компіляції та запуску програми потрібен Rust (версія не нижче 1.56).
- **Windows API** — програма використовує бібліотеку `windows` для керування енергоспоживанням та моніторингу активності користувача.

## Установка та запуск

1. Встановіть [Rust](https://www.rust-lang.org/).
2. Клонувати репозиторій програми:
   
   ```git clone <URL вашого репозиторію>```

3. Перейдіть до каталогу проекту: 

    ```cd <назва_текі_програми>```

4. Встановіть залежності:

    ```cargo build```

5. Запустіть програму:

    ```cargo run```
